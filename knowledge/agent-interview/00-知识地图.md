# Agent 开发面试知识地图

更新时间：2026-11-18。定位：Agent Developer、LLM Application Engineer、AI 应用后端岗位的通用参考资料。本目录是技术知识库，不证明候选人做过其中任何方案；个人经历只能以简历、项目记录或本人明确陈述为准。

## 第一批学习目标

第一批覆盖 Agent 架构、规划推理、工具工程、Context 与 Memory、RAG、Agent 评测六个核心模块。学习顺序不是按名词难度排列，而是按一次真实任务的数据流排列：先确定 Agent 的控制边界，再讨论如何规划、怎样调用工具、状态与记忆如何保存、外部知识如何检索，最后用评测判断系统是否真的有效。

## 第二、三批学习目标

第二批面向生产工程：多 Agent 编排、MCP/A2A 与框架、Prompt 和结构化输出、安全治理、可观测、部署性能与成本。第三批补齐岗位外延：LLM/Transformer 原理、模型选择与微调、Python 异步与分布式、Agent 系统设计、典型案例与项目深挖表达。

## 模块一：Agent 架构与执行循环

核心问题：Agent 与 Chatbot、固定 Workflow 有什么区别；模型、工具、状态和控制器分别负责什么；Observe-Plan-Act 如何循环；什么时候应该使用确定性流程；怎样设计终止条件、人工接管、检查点和失败恢复。

检索词：Agent、智能体、Agent Loop、执行循环、Workflow、工作流、状态机、Orchestrator、编排、自主决策、终止条件、Human-in-the-loop。

## 模块二：规划推理与任务分解

核心问题：ReAct、Plan-and-Execute、Reflection 各自解决什么问题；怎样把目标转成可验证步骤；执行结果变化后如何重规划；为什么不能把模型生成的计划直接视为正确；如何限制搜索空间、预算和循环次数。

检索词：Planning、规划、Reasoning、推理、Task Decomposition、任务分解、ReAct、Reflection、反思、Replanning、重规划、Critic、Verifier。

## 模块三：Tool Calling 与工具工程

核心问题：工具描述和参数 Schema 如何设计；怎样处理无效参数和业务校验；只读操作与有副作用操作如何区分；超时、重试、幂等、取消、权限、沙箱和人工确认怎样组合；工具结果为什么仍是不可信输入。

检索词：Tool Calling、Function Calling、函数调用、工具选择、Structured Output、结构化输出、Schema、幂等、副作用、Retry、Timeout、Sandbox、权限。

## 模块四：Context 与 Memory

核心问题：Context Window、Working Memory、Episodic Memory、Semantic Memory 和用户画像有什么区别；哪些状态必须精确保存；如何摘要、检索、遗忘和处理冲突；长期记忆写入为何需要准入、来源和更新时间。

检索词：Context、上下文、Memory、记忆、Working Memory、工作记忆、Episodic、情景记忆、Semantic、语义记忆、Summary、摘要、遗忘、冲突。

## 模块五：RAG 与知识库

核心问题：文档如何解析、切块、索引、召回、重排和引用；词法检索、向量检索与混合检索如何选择；Query Rewrite 有什么风险；如何评测检索和生成；如何防止知识库内容实施 Prompt Injection。

检索词：RAG、检索增强生成、Retrieval、召回、Chunking、切块、Embedding、向量、BM25、Hybrid Search、混合检索、Rerank、重排、Citation、引用。

## 模块六：Agent 评测

核心问题：为什么只看最终答案不够；怎样分别评测结果、过程轨迹和系统运行；如何建设 Golden Dataset、工具模拟器和回归集；规则、人工评审与 LLM-as-Judge 如何组合；怎样控制泄漏、随机性和评测成本。

检索词：Agent Evaluation、Agent 评测、Evals、Benchmark、Golden Dataset、任务成功率、Tool Accuracy、Trajectory、轨迹评测、LLM-as-Judge、回归测试。

## 模块七：多 Agent 协作与编排

核心问题：什么时候需要多 Agent；Router、Supervisor、Handoff、Planner-Workers 和 Blackboard 有什么取舍；怎样定义交接契约、权威状态、全局预算、冲突合并与失败隔离。

检索词：Multi-Agent、多智能体、Supervisor、Handoff、Router、Planner-Workers、Blackboard、交接、冲突、编排。

## 模块八：MCP、A2A 与框架选型

核心问题：MCP Host、Client、Server、Tools、Resources 分别负责什么；MCP 与 Function Calling、A2A 如何分层；能力发现为什么不等于授权；怎样根据状态、恢复、Trace、测试性与锁定成本选框架。

检索词：MCP、Model Context Protocol、Host、Client、Server、Tools、Resources、A2A、Agent-to-Agent、LangGraph、Agents SDK、AutoGen。

## 模块九：Prompt 与结构化输出

核心问题：Prompt 如何分层和版本化；指令与外部数据如何分离；Few-shot 如何覆盖边界；JSON mode 与 Schema 约束有什么差异；为什么格式正确仍需要业务、事实与权限校验。

检索词：Prompt Engineering、System Prompt、Few-shot、Structured Output、JSON mode、JSON Schema、Constrained Decoding、Prompt Version。

## 模块十：Agent 安全、权限与治理

核心问题：如何做威胁建模；如何在 Prompt Injection 无法完全识别时控制影响；认证、资源级授权、凭据、沙箱、网络出口、租户隔离、人工确认和审计如何组合。

检索词：Agent Security、Prompt Injection、Jailbreak、Authorization、授权、Least Privilege、Sandbox、SSRF、Data Exfiltration、数据外泄、Audit。

## 模块十一：Agent 可观测与故障排查

核心问题：怎样用 Trace 串联模型、检索、工具、状态和人工；Logs、Metrics、Traces 如何分工；怎样从结果、轨迹和系统三层监测；为什么模型不能完全重放，线上失败如何转为回归。

检索词：Observability、Tracing、Span、Logs、Metrics、Replay、OpenTelemetry、Root Cause、根因、SLO。

## 模块十二：生产部署、性能与成本

核心问题：同步与异步任务如何区分；并行、有界队列、背压、限流、超时、重试和断路器如何配合；缓存、Singleflight、模型路由与降级如何选；怎样计算每成功任务成本。

检索词：Deployment、Latency、Throughput、Queue、Backpressure、Rate Limit、Retry、Circuit Breaker、Caching、Singleflight、Cost、Canary。

## 模块十三：LLM 与 Transformer 基础

核心问题：Tokenization、Embedding、Self-Attention、位置信息、自回归目标、Temperature、Top-p、KV Cache、prefill 和 decode 分别是什么；为什么这些机制不自动保证事实与外部状态。

检索词：LLM、Transformer、Token、Tokenizer、Embedding、Self-Attention、Query Key Value、Autoregressive、Temperature、Top-p、KV Cache、prefill、decode。

## 模块十四：模型选择、微调与推理优化

核心问题：怎样根据内部任务集选模型；Prompt、RAG 与微调各解决什么；SFT、PEFT/LoRA、偏好优化、蒸馏和量化的目标与失败是什么；自托管和 API 如何权衡。

检索词：Model Selection、SFT、Fine-Tuning、PEFT、LoRA、Preference Optimization、Distillation、Quantization、Inference、Self-hosting。

## 模块十五：Python 异步与分布式基础

核心问题：Event Loop、Coroutine、Task、Thread、Process 如何选；取消、超时、信号量、连接池与背压如何实现；队列为什么需要幂等；Outbox、乐观并发和 Saga 解决什么问题。

检索词：Python、asyncio、async/await、Event Loop、Coroutine、TaskGroup、GIL、Thread、Process、Semaphore、Queue、Idempotency、Outbox、Saga。

## 模块十六：Agent 系统设计方法

核心问题：怎样澄清需求和 SLO；怎样定义可验证成功、禁止动作、信任边界和权威状态；怎样讲主链路、具体故障、数据与容量；如何从离线评测逐步上线。

检索词：Agent System Design、Requirements、SLO、Trust Boundary、State Machine、状态机、Capacity Planning、容量规划、Failure Recovery、故障恢复。

## 模块十七：典型 Agent 系统设计案例

核心问题：Research Agent 如何做 Claim-Evidence；Coding Agent 如何沙箱执行与验证 diff；客服 Agent 如何用政策服务、确认与幂等执行副作用；Data Analyst Agent 如何用语义层、SQL AST 与数据库权限防越界。

检索词：Research Agent、Coding Agent、Customer Support Agent、Data Analyst Agent、Text-to-SQL、Claim-Evidence、Sandbox、Refund、Semantic Layer。

## 模块十八：Agent 项目追问与技术表达

核心问题：怎样用一分钟讲清项目；怎样界定个人贡献；如何用约束、候选、取舍和验证表达技术决策；指标口径和故障复盘如何准备；遇到没做过的问题如何不虚构事实地推理。

检索词：Project Deep Dive、项目深挖、STAR、Architecture Decision、Trade-off、Incident Review、Postmortem、Metric、个人贡献、故障复盘。

## 面试回答的统一结构

技术问题优先按五步回答：先给结论；再解释一条核心机制；接着指出一个关键失败场景；然后说明工程取舍；最后给验证指标。不要先罗列框架名，也不要把“可以使用某技术”写成“必须使用某技术”。

系统设计问题优先按八步回答：目标与成功标准、权限边界、状态模型、执行循环、工具和外部系统、失败恢复、安全控制、评测与观测。模型选择和框架选择应服务于这些约束，而不是答案的起点。

## 事实边界

本目录中的实现方式属于通用知识或设计建议。面试官问“你做过什么”时，只有项目材料明确记载的角色、动作、指标和故障可以使用第一人称过去式。未落地的方案应说“我会这样设计”或“如果采用该方案”，没有实测指标时必须说明尚未验证。
