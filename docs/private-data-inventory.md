# 私有数据清单

本清单仅记录类别、路径模式和风险，不记录简历、论文、职位描述、面试对话、密钥或材料正文。清单用于防止工作区整目录发布，不表示这些数据应被移动或删除。

## 清单

| 类别 | 当前路径或模式 | 可能包含的信息 | 处理边界 |
| --- | --- | --- | --- |
| 本地配置 | `config.json`、`.env`、`*.local.json` | API 配置、环境变量名、本机绝对路径、服务端点 | 永不提交；只发布 `config.example.json` |
| 个人简历 | `resume.md`、`data/resume.txt` | 身份、经历、项目与联系方式 | 永不提交，不复制正文 |
| 简历路径元数据 | `data/resume_meta.json` | 原始文件名、来源或本机路径等元数据 | 永不提交 |
| 论文材料 | `data/papers/` | 论文解析文本、缓存和文档元数据 | 永不提交 |
| 论文路径元数据 | `data/papers_meta.json`、`data/papers/*.json` | 原始文件名、来源或本机路径等元数据 | 永不提交 |
| 职位描述（JD） | `data/jd.md` | 目标岗位、公司或面试上下文 | 永不提交 |
| 其他面试材料缓存 | `data/materials/` | 上传材料、解析文本、缓存、来源元数据 | 永不提交 |
| 面试历史数据库 | `data/history.db` | 会话、问题、回答或检索记录 | 永不提交 |
| SQLite 联机辅助文件 | `data/history.db-wal`、`data/history.db-shm` | 尚未合并的事务页、共享内存状态，可能含历史正文片段 | 永不提交；不得仅复制主数据库而遗漏其风险 |
| 本地音频与日志 | `*.wav`、`*.log`、`logs/` | 语音、转写线索、错误上下文、路径或请求信息 | 永不提交 |
| 上传/导出临时文件 | `paper_up.*`、`mat_up.*`、`resume_up.*`、`*.md.tmp` | 原始或转换后的个人材料 | 永不提交 |
| 个人诊断脚本与旧报告 | `.gitignore` 中列出的 `diag_*.py`、辅助脚本和中文旧报告 | 本机路径、调试端点、历史结论或个人工作流 | 永不提交，除非单独脱敏审查后重写 |
| 本地环境与缓存 | `venv/`、`.venv/`、`__pycache__/`、`.pytest_cache/` | 第三方包、本机环境路径、生成缓存 | 不属于源码发布；永不提交 |

## `data/` 文件类型盘点

只读盘点确认 `data/` 当前包含以下类型，不在本文记录具体正文：

- SQLite 主库及 WAL/SHM 文件；
- Markdown 与 TXT 文本；
- JSON 元数据和缓存；
- `materials/` 与 `papers/` 缓存目录；
- 缓存目录中的上传/转换产物。

`data/` 采用整目录禁止提交，而不是按扩展名单放行。这样可覆盖未来新增的数据库辅助文件、未知缓存格式和包含个人信息的新材料。

## 操作约束

1. 不移动、不删除现有私有数据，保证旧版仍可使用。
2. 不把工作区根目录直接压缩为发布包；发布内容应从已审查的版本控制文件生成。
3. 不因文件名经过哈希化就视为匿名；缓存正文和关联元数据仍按私有数据处理。
4. SQLite 备份或迁移时将 DB、WAL、SHM 视作同一敏感数据组。
5. 对外共享日志、诊断输出或测试夹具前，人工检查其中的绝对路径、端点、姓名、公司、问题和回答。
6. 发现新的个人材料或路径元数据时，优先放入已忽略的 `data/`，并更新本清单；不要放宽现有忽略规则。
