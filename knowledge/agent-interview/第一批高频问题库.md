# 第一批 Agent 开发高频问题库

使用方式：先尝试口述，再按“考察点”回到对应模块。问题库只提供技术框架，项目经历必须结合真实材料。

## Agent 架构

### Agent、Chatbot 和 Workflow 有什么区别

考察点：谁控制下一步、自治是否必要、如何组合确定性流程与模型判断。回答应说明 Agent 不是“调用了 LLM”就成立。

### 怎样设计一个 Agent Loop

考察点：目标、状态、动作、Observation、控制器、验证、终止和 Trace。追问可能要求画数据流或状态机。

### 怎样避免死循环和重复调用

考察点：多维预算、重复检测、状态进展、完成验证、澄清和人工接管。不要只回答“设置最大轮数”。

### Agent 服务重启后如何恢复

考察点：检查点、外部权威状态、幂等键、未知结果、补偿。对话重放不能保证副作用一致性。

### 哪些决策不应该交给模型

考察点：权限、合规、金额、状态转换、资源边界和成功判定应由代码或策略服务控制。

## 规划与推理

### ReAct 和 Plan-and-Execute 的区别

考察点：动态观察、全局阶段、任务长度、重规划成本；可以给出分层组合方案。

### 如何把复杂目标拆成步骤

考察点：前置条件、输入、工具、产物、验证器和依赖；步骤不能是不可验证的泛化描述。

### Reflection 为什么可能无效

考察点：缺少新证据、同源偏差、成本、反馈是否可执行；客观条件优先外部 Verifier。

### 什么时候需要重规划

考察点：关键假设失效、依赖冲突、不可恢复错误、目标变化和无进展；瞬时错误不必全量重规划。

### 是否应该要求模型输出 Chain-of-Thought

考察点：系统需要可审计的动作、简短理由和证据，不依赖暴露私有思维链；可靠性来自状态、工具和验证。

## Tool Calling

### Function Calling 是否能保证调用正确

考察点：格式与语义的区别；Schema、业务校验、资源权限和用户授权仍由应用负责。

### 工具超时后如何处理

考察点：未知结果、查询与写入区别、幂等键、状态查询、退避和补偿。

### 怎样设计幂等工具

考察点：稳定业务意图键、服务端持久化、原子去重、同键异参拒绝、结果复用。客户端内存去重不足。

### 多个工具是否可以并行

考察点：依赖图、读写冲突、共享预算、限流、局部失败和结果合并。

### 怎样防止工具被 Prompt Injection 利用

考察点：工具结果是数据、最小权限、风险审批、参数约束、网络与文件沙箱；不能只靠 Prompt。

### 取消 Agent 后工具是否也取消

考察点：取消信号传播、旧结果代次、外部副作用、补偿和用户状态表达。

## Context 与 Memory

### Context 和 Memory 有什么区别

考察点：当前输入与持久信息；Memory 需要被检索和注入才能影响模型。

### Working、Episodic、Semantic Memory 如何区分

考察点：当前任务状态、过去事件、稳定事实；分别说明生命周期和检索方式。

### 长对话怎样压缩

考察点：分层摘要、关键状态结构化、来源追溯、版本与并发；不能简单截掉前半段。

### 怎样处理冲突记忆

考察点：来源权威、时间、作用域、用户确认和显式不确定；最新不一定总是正确。

### 什么内容不应写入长期记忆

考察点：模型推断、短期噪声、敏感数据、外部恶意指令、无来源事实和一次性任务状态。

### Memory 怎样做隐私隔离

考察点：租户与用户过滤、访问控制、加密、保留期限、派生数据删除和审计。

## RAG

### 一个完整 RAG 系统有哪些环节

考察点：解析、切块、索引、查询、召回、重排、组装、生成、引用和评测。

### BM25 与向量检索怎样选择

考察点：精确术语与语义表达、混合召回、基线和错误分布。不要默认向量一定更好。

### Chunk 多大合适

考察点：文档结构、问题粒度、上下文、父子块和目标问题集评测。没有固定答案。

### Query Rewrite 有什么风险

考察点：意图漂移、数字、实体和否定词；保留原查询并结构化锁定关键约束。

### 有引用是否表示回答可靠

考察点：引用存在与 Claim-Evidence 支持不同；需检查蕴含、限定条件和来源版本。

### RAG 怎样防止数据越权

考察点：召回前权限过滤、索引隔离、缓存和日志、引用授权。不能生成后再过滤。

## Agent 评测

### 怎样系统评测一个 Agent

考察点：结果、轨迹、系统三层；权威状态、工具调用、安全、延迟和成本。

### Golden Dataset 应包含什么

考察点：真实分布、历史失败、无答案、歧义、工具故障、攻击、成功和禁止动作。

### LLM-as-Judge 有什么问题

考察点：顺序、长度、措辞、同模型偏好、环境不可见和注入；需要人工校准。

### 多条正确轨迹怎么评分

考察点：最终状态、必要节点、禁止动作和效率，而不是逐步匹配唯一答案。

### 怎样证明版本提升不是偶然

考察点：配对样本、重复运行、置信区间、分层指标和变量控制；小样本百分比不足以下结论。

### 线上失败怎样转成回归测试

考察点：脱敏、复现初始环境、Fake 工具、失败分类、版本化和独立保留集。
