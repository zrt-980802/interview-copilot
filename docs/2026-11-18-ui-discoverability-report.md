# 前端导航与操作可见性优化

日期：2026-11-18。基于 `v2-restructure` 的 `a8dbba8` 继续修改，本轮未提交或推送。

## 界面变化

- 电脑端四个页面统一使用常驻文字导航：面试工作区、资料库、历史复盘、模型设置。当前页有明确标识，窄屏仍直接显示四个入口。
- 工作区将声音设备和采集命令放在独立区域，明确区分面试官系统声音与本人麦克风，显示采集状态；开始监听、暂停采集、校准均有可见名称。
- 会话工具条直接显示管理简历、手机显示、新会话；底部显示手动提问入口；取消生成使用固定尺寸的图标与文字。增加可在会话恢复后保留的空状态。
- 资料库突出资料类型、上传文件和 GitHub 导入，详情显示下载原文件、归档/恢复、保存属性；历史复盘明确刷新、返回列表、复制和导出命令。
- 模型设置将保存配置固定在表单底部，主备服务正文独立滚动；密钥清除命令显示文字。
- 手机端明确最新题、专注显示、主题、屏幕常亮与断开配对，字号控制显示当前数值。保留独立手机入口和原有权限范围。
- 统一焦点、间距、按钮与导航样式，处理长文本、低矮横屏、窄屏和 200% CSS 缩放下的布局。

## 操作缺陷修复

资料属性尚在保存时，归档按钮此前仍可点击，动作会被 `saving` 守卫静默忽略。现在保存及重新初始化期间统一禁用冲突操作，并标记详情忙碌状态，结束或失败后恢复。启用复选框在等待保存时保留用户选择，失败后恢复服务端状态。

新增延迟请求与失败恢复回归。另修正原有测试夹具：上传内容带本次唯一标记，避免重复运行被内容去重关联到旧文件；历史会话按本次创建的 ID 选择，避免同名记录歧义。
