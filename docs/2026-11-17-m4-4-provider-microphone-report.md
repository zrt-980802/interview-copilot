# M4-4：网页模型配置与本人发言上下文

日期：2026-11-17。基于当前 `v2-restructure` 工作区继续开发，保留此前资料库、手机端、历史与内容改动，未提交或推送。

## 本批结果

- 新增本机 `/settings` 模型设置，工作区工具栏提供入口。支持 OpenAI 兼容地址、Provider 预设、自定义服务、主密钥、快速/深入模型、备用服务、无需认证、获取模型、测试连接与保存。
- 密钥输入为空保持已有值，明确清除后保存才删除。页面与 API 不回显密钥，不写入 URL 或浏览器 localStorage。
- 新密钥可用 Windows 当前用户的 DPAPI 加密保存到本地被忽略的 `data/provider_settings.db`，或仅在当前进程保留。只用合成字符串验证了实际 Windows 加解密与重启读取，未修改用户真实凭据。
- 改地址时取消原地址凭据与环境变量回退；旧客户端保留原地址/密钥快照，新任务使用新配置。保存不终止进行中的回答，停机关闭当前与旧客户端。
- 版本号冲突不会覆盖其他窗口的新配置。连接测试不会保存配置，只发送固定短消息，不附带个人资料；模型发现与连接测试仅请求所选通道。
- 配置页/API 仅允许回环管理入口、拒绝跨站、禁止缓存；手机监听器没有配置入口。格式错误的 Provider 请求也不回显请求正文中的凭据。

## 麦克风修复

页面以前只在有输入设备时追加选项；离线预览设备清单为空时仅剩“不录我”。现在始终提供系统默认麦克风、关闭选项和可枚举设备，默认选择本人麦克风，打开页面不自动采集。点击监听后启动所选通道，监听中可切换或关闭本人通道，设备列表变化可刷新。

两个实际上下文缺陷已修复：

1. 单段回答超过预算时，旧缓冲循环会整段丢弃甚至返回空；现保留最近的预算内文本。
2. 深挖任务创建后题目快照发生变化，旧代码的整体快照比较误判“非当前题”，不注入本人发言；现按稳定题目 ID 判断。

合成回归验证：本人转写不触发题目，长回答进入下一题快速上下文，当前题深挖包含当前发言，AI 建议不会混作本人发言，新会话清空缓冲。
