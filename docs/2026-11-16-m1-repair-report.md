# M1 缺陷修复与离线验证

日期：2026-11-16
分支及基线：`v2-restructure` / `6be3112`
结论：本批 B01-B07 修复通过离线回归。整体质量提升计划尚未完成，真实音频和模型回答质量尚未验收。

## 修复范围

| 编号 | 实现 | 主要验证 |
| --- | --- | --- |
| B01 深挖报错 | 用明确的题目和子卡状态管理 DOM，失败后可重试 | 浏览器旧题深挖及失败重试 |
| B02 回答串题 | 每个任务捕获 session、turn、generation、task 和方向；回调和持久化使用原始归属 | 新题生成期间完成旧题深挖；HTTP 选择旧题 |
| B03 清空后旧内容回流 | 取消题目合并计时器，使问答和双路音频的在途结果失效，切换会话并广播重置 | 清空后迟到的转写、计时器和模型回调被拒绝；双窗口清空 |
| B04 线程乱序 | 接收问题时同步创建 turn 和 generation，工作线程只执行已分配的任务 | 交换线程执行顺序仍只回答新题 |
| B05 上传覆盖 | 每次上传使用独立临时目录和独立原件归档，保留原名称和来源元数据 | 并发同名上传、同名不同内容、重载、超限与失败清理 |
| B06 历史归属 | 队列命令在入队时捕获 session；turn 完成信号等待事务结束 | 临时 SQLite 跨会话写入、提交可见性、回滚后不返回无效 ID |
| B07 热词截断 | 传入完整简历文本；简历上传、重载后刷新热词 | 完整技术词传递与简历上传路由 |

直接相关的补充修复：

- 新增 v2 `SessionManager`，按会话登记和取消任务；旧题深挖可在新题开始后继续完成。
- 模型收到取消信号后不再触发备用模型调用。当前实现以回调失效为主，不能立即中止尚未返回数据的 HTTP 请求。
- 手动提问和深挖参数类型或长度错误返回客户端错误，过期会话的深挖返回冲突。
- 上传采用 25 MiB 应用层限制，解析和摘要处理放入工作线程，成功或失败都会清理临时文件。此限制不等于 multipart 请求入口的完整内存限流。
- 简历上传保留独立原件，避免元数据指向已删除的临时文件；上传与重载串行处理，重载前不再删除当前简历。
- 论文摘要为空后重载仍保留原文件名；材料来源元数据写入加锁，避免并发上传丢失来源。
- 工具栏支持换行、按钮避免竖排挤压，增加真实 SSE 连接状态，移除误导性的窗口可见性提示。

未修改回答 Prompt、模型选择或检索策略；页面主体仍沿用旧版。这一批不构成回答质量提升或整体 UI 改版。

开发中的失败验证包括：最初七个旧入口回归失败、SessionManager 缺失、同扩展名材料覆盖、三项浏览器交互失败，以及最后补充的论文重载名称断言失败；修复后上述检查全部通过。最终数据库测试同时验证提交成功和批次回滚，确保返回的 turn ID 有实际提交记录。

唯一 Python 警告来自当前安装的 Starlette TestClient 对 httpx 的弃用提示；没有因此改动依赖版本。

可复现命令（仓库根目录）：

```powershell
.\venv\Scripts\python.exe -m pytest tests -q
```

浏览器测试需要 Node、可用的 `playwright` 包与 Edge。本次使用 Codex 自带的 Playwright 包，通过 `NODE_PATH` 指向其安装目录，没有新增生产依赖或下载浏览器。

```powershell
# 终端一：离线回归预览，使用固定合成回答。
.\venv\Scripts\python.exe tests\regression\run_preview.py --port 8537

# 终端二：NODE_PATH 已指向可用的 Playwright 包目录。
$env:PLAYWRIGHT_CHANNEL = 'msedge'
$env:INTERVIEW_PREVIEW_URL = 'http://127.0.0.1:8537'
node --test tests\frontend\legacy-events.test.cjs
```

没有设置 `INTERVIEW_PREVIEW_URL` 时，前三项浏览器测试仍运行，真实 HTTP/SSE 场景会跳过，不能据此声称四项全部通过。

本机截图位于 `%TEMP%\interview-copilot-m1-20261116\`。预览仅绑定 `127.0.0.1:8537`，运行实际 HTTP/UI 入口并替换设备、持久化和 provider；不读取个人配置、简历或历史，不采集音频，不请求真实模型。它只验证事件链路和页面行为，不能用于评价答案是否聪明。
