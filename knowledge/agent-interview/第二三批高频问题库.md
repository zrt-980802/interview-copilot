# 第二、三批 Agent 开发高频问题库

使用方式：先用 20 秒给结论，再回到对应专题展开。问题库只提供通用考察点；项目经历、规模和指标必须来自真实材料。

## 多 Agent 协作

### 什么时候应该从单 Agent 拆成多 Agent

考察点：工具、Context、权限隔离，可独立验收，先有单 Agent 基线。

### Supervisor 和 Handoff 有什么区别

考察点：全局控制、对话控制权、交接契约、状态与权限。

### 多个 Agent 结论冲突怎么办

考察点：来源权威、时效、外部重读、保留分歧和人工处理。

### 多 Agent 怎样防止成本失控

考察点：全局与子任务预算、并发上限、终止、重复工作和单 Agent 对照。

## MCP、A2A 与框架

### MCP 和 Function Calling 是一回事吗

考察点：模型-应用动作表达与 Host-Server 能力接入不在同一层。

### MCP Host、Client 和 Server 分别做什么

考察点：用户应用与策略、单 Server 协议会话、Tool/Resource/Prompt 能力。

### 用了 MCP 为什么还要自己做授权

考察点：能力发现不等于授权，Server 内容不可信，资源级检查与凭据隔离。

### 怎样选 Agent 框架

考察点：状态、检查点、取消、人工审批、Trace、测试性、数据可迁移与逃生口。

## Prompt 与结构化输出

### System Prompt 应该放哪些内容

考察点：稳定目标、边界、动作、输出和失败行为；外部资料与指令隔离。

### Prompt 越长效果越好吗

考察点：指令冲突、关键约束稀释、Token 和延迟，消融评测。

### JSON mode 和 Structured Outputs 有什么区别

考察点：合法 JSON 与符合 Schema 的区别，供应商 Schema 子集，应用二次验证。

### 结构化输出能不能防止幻觉

考察点：格式不等于语义或事实，证据、业务校验和权限仍必需。

## 安全、权限与治理

### Prompt Injection 无法完全识别时怎么防

考察点：假设模型被误导，用最小权限、资源授权、参数校验、出口限制与确认控制影响。

### 认证和授权有什么区别

考察点：身份与对特定资源动作的权利，每次工具服务端重新检查。

### 为什么检索要在召回前做权限过滤

考察点：越权文本一旦进入 Context 已存在泄露风险，索引、缓存与日志也需隔离。

### 有人工确认就可以执行高风险操作吗

考察点：知情确认、动作参数绑定、执行前重新授权、幂等与审计。

## 可观测与排障

### Agent Trace 应该记录什么

考察点：根任务、模型、检索、工具、状态、审批、版本和脱敏摘要。

### Logs、Metrics 和 Traces 分别解决什么

考察点：离散事件、聚合趋势/告警、单任务跨组件因果与延迟。

### 线上 Agent 答错了怎样定位

考察点：输入、检索、规划、工具、状态、合并、生成分层，固定 Observation 做消融。

### 为什么 Agent 不能承诺完全重放

考察点：采样、提供商后端、外部状态与时序；版本、快照和 Fake 工具用于可控复现。

## 部署、性能与成本

### 怎样降低 Agent 的端到端延迟

考察点：Trace 分解、减少轮次/Context、关键路径并行、缓存、路由、流式与显式降级。

### 流量突发时为什么不能无限排队

考察点：截止时间、内存、队头阻塞、级联超时，有界队列、背压和租户公平。

### 多层重试会有什么问题

考察点：尝试数乘法放大、下游雪崩、只在理解业务语义的一层重试。

### 怎样衡量 Agent 的真实成本

考察点：Token、Embedding、工具、计算、存储、观测与人工，核心是每成功任务成本。

## LLM 与 Transformer 基础

### Self-Attention 是怎样工作的

考察点：Query-Key 权重、Value 汇总、多头、因果遮罩、位置信息。

### Token 和字或单词有什么区别

考察点：Tokenizer 与词表、子词/字节、多语言和代码的成本差异。

### Temperature 设为 0 就能完全复现吗

考察点：采样更稳定但后端、数值、版本和同分选择仍可产生差异。

### KV Cache 解决了什么问题

考察点：缓存历史 Key/Value 避免重算，改善 decode，但长 Context 与并发增加显存。

## 模型选择、微调与推理

### Prompt、RAG 和微调怎么选

考察点：任务指令、可更新事实、稳定行为三类问题，基线与可测收益。

### 什么时候值得微调

考察点：强基线仍有稳定失败，足够高质数据，明确指标与训练/部署成本。

### LoRA 为什么节省训练资源

考察点：冻结基座权重、低秩更新、更少可训参数，但数据与评测成本仍在。

### 量化一定会让模型更快吗

考察点：内存带宽、硬件算子、批处理、位宽和质量取舍，目标任务实测。

## Python 异步与分布式

### async 为什么不会让 CPU 任务更快

考察点：协作式让出主要隐藏 I/O 等待，CPU 计算仍占用事件循环。

### 怎样把同步工具接到 async Agent

考察点：I/O 用有界线程池，CPU 用进程/独立服务，取消限制与并发上限。

### 为什么队列消费者必须幂等

考察点：至少一次交付、Worker 崩溃与租约超时、业务意图键与数据库原子去重。

### Outbox 解决了什么问题

考察点：业务数据与待发事件同事务，Relay 可重复，消费者仍要幂等。

## Agent 系统设计

### 设计 Agent 系统时第一步应该问什么

考察点：目标用户、高频任务、可执行副作用、成功/禁止动作、规模和数据约束。

### Agent 的权威状态应该放在哪里

考察点：应用持久化存储和状态机，Context 只是投影，检查点、世代与幂等。

### 系统设计题怎样讲故障恢复

考察点：具体故障、检测、可重试性、状态持久化、用户可见状态、恢复/补偿。

### 怎样估算 Agent 系统容量

考察点：峰值到达率、任务时长、多轮与重试系数、在途任务、模型/工具/数据库瓶颈。

## 典型 Agent 案例

### Research Agent 怎样避免引用幻觉

考察点：系统分配来源 ID、原文访问、Claim-Evidence 对齐、时效、冲突与无支持 Claim 降级。

### Coding Agent 怎样判定真的完成

考察点：目标测试、静态检查、构建、diff 范围、沙箱与未验证状态。

### 客服 Agent 为什么不让模型计算退款

考察点：可编程高风险规则由政策服务执行，模型负责解释，金额与外部状态验证。

### Text-to-SQL Agent 怎样防止越权和大查询

考察点：语义层、AST 白名单、只读账户、行列策略、超时、扫描上限和资源组。

## 项目追问与表达

### 如何用一分钟介绍 Agent 项目

考察点：用户问题、可验证目标、主链路、个人责任、有口径的结果与边界。

### 怎样说清项目中的个人贡献

考察点：动词与产物、直接责任边界、团队协作、接口与验收。

### 项目故障复盘应该怎么讲

考察点：影响、发现、触发与根因、止损、长期修复、回归/监控和剩余风险。

### 没有上线指标时怎么回答

考察点：如实说明阶段，提供已有离线证据，区分已测与计划测量，不编造数字。
