# 麦克风提问测试

日期：2026-11-20。

在电脑工作台“声音采集”中，先暂停采集，再勾选“麦克风提问测试”，选择麦克风并点击“开始监听”。此时只启动麦克风，它的语音作为面试官问题触发回答；系统声音采集停用。兼容流程和连续语音流程都支持，连续流程的草稿编辑、提交和放弃仍可使用。

退出时先暂停采集，再取消勾选。麦克风恢复记录本人回答，并为后续问题提供上下文。该设置在当前服务进程内保留，刷新页面、新会话、切换语音流程都不会退出；服务重启默认关闭。勾选开关本身不会开启录音。

实现保留`source=mic`作为采集身份，与`speaker=interviewer`的提问角色分开；旧批次结果在切换时失效。手动提问、暂停采集均取消麦克风的待提交问题，切换不清除会话或撤销手机配对。手机仍只收到正式问题和回答。

验证涵盖两种流程的路由、麦克风批次校验、旧结果丢弃、草稿手动提交、恢复本人上下文、单路启动、刷新恢复、窄屏布局和切换失败恢复。额外以已知合成中文语音通过真实Silero、Smart Turn和本地Whisper麦克风引擎验证，得到一次`interviewer/accept_question`提交；未打开实际录音设备。
