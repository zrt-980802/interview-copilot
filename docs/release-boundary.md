# 发布边界

本文档定义当前仓库的发布与私有数据边界。它只记录路径和文件类型，不授权公开任何本地内容。旧版入口与现有源码均保持原位。

## 工作区只读盘点

盘点范围为项目根目录与 `data/`；未读取或复制文件正文。

| 区域 | 当前可见类型 | 边界判断 |
| --- | --- | --- |
| 根目录 | Python 源码与测试、HTML、批处理启动脚本、Markdown、JSON、WAV | 源码候选、模板、个人材料和运行产物混合，须按下表分类 |
| `copilot/` | Python 包源码 | 源码候选 |
| `static/` | Web 静态文件 | 源码候选 |
| `docs/` | 设计与边界文档 | 文档候选 |
| `data/` | Markdown、TXT、JSON、SQLite DB/WAL/SHM，以及材料与论文缓存目录 | 私有运行数据，禁止发布 |
| `venv/` | 本地 Python 环境及第三方包 | 可重建环境，禁止发布 |
| `__pycache__/` | Python 字节码缓存 | 可重建缓存，禁止发布 |
| `logs/` | 运行日志目录（当前可为空） | 运行生成，禁止发布 |
| 根目录诊断/临时文件 | `diag_*.py`、被单独排除的辅助脚本、音频与上传临时文件 | 个人诊断或运行产物，禁止发布 |

## 四类边界

### 1. 可提交

面向源码发布、且不包含本地凭据或个人材料的候选：

- `.gitignore`
- `README.md`
- `server.py`
- `copilot/`
- `static/`
- `docs/`
- 当前已跟踪的 `test_*.py` 自动化测试
- `启动面试辅助.bat`

“可提交”不等于已经完成发布审查；提交前仍须检查新增文件是否包含密钥、绝对路径、个人信息或运行数据。

### 2. 模板

- `config.example.json`：可提交的配置模板。路径字段保持为空，服务地址使用示例或本机地址，密钥只写环境变量名。
- 新增配置示例必须去除真实密钥、真实外部 API 地址、个人路径和材料名称。

### 3. 运行生成

这些内容由运行、上传、缓存、测试或本地环境产生，可删除后重建，不属于源码发布：

- `data/` 下的 SQLite 数据库及 `-wal`、`-shm` 辅助文件
- `data/materials/`、`data/papers/` 及其 TXT/JSON/Markdown/Python 缓存或上传副本
- `data/*_meta.json`
- `logs/`、`*.log`、`*.wav`
- `__pycache__/`、`*.py[cod]`、`.pytest_cache/`
- `venv/`、`.venv/`
- `paper_up.*`、`mat_up.*`、`resume_up.*`、`*.md.tmp`

运行生成内容如同时含个人资料，按“永不提交”处理。

### 4. 永不提交

- `config.json`、`.env`、`*.local.json`：本地配置、密钥引用和路径信息
- `data/` 全目录：面试历史、JD、简历、论文、材料、缓存和路径元数据
- 根目录 `resume.md`
- `venv/`、`.venv/`、`__pycache__/`、`.pytest_cache/`、`logs/`
- `*.log`、`*.wav`
- 个人诊断与旧报告：`agent_helper_test.py`、`diag_*.py`、`e2e_app_test.py`、`probe_reasoning.py`、`rehearse.py`、`test_fixes.py`、`三期计划-知识库持久化.md`、`使用说明.md`、`项目总结报告.md`
- 临时导出与上传副本：`*.md.tmp`、`paper_up.*`、`mat_up.*`、`resume_up.*`

上述路径已由 `.gitignore` 覆盖；本次补充了 `logs/`。若未来需要发布某个诊断工具，应先去除本地路径和个人数据依赖，再以新的、明确审查过的源码文件加入，而不是直接解除忽略规则。

## 待人工确认的发布候选清单

发布前由维护者逐项确认：

- [ ] `README.md` 的安装、启动和依赖说明与实际发布方式一致。
- [ ] `server.py`、`copilot/`、`static/` 不含密钥、个人绝对路径或样本正文。
- [ ] 已跟踪的 `test_*.py` 只包含合成/匿名夹具，不依赖本机私有材料或真实服务。
- [ ] `启动面试辅助.bat` 不绑定仅适用于当前机器的路径或环境。
- [ ] `config.example.json` 只含安全占位值，并覆盖用户所需配置项。
- [ ] `docs/` 中只保留适合公开的架构和使用文档；内部计划另行审定。
- [ ] 发布包由版本控制中的候选文件构建，不从工作区整目录打包。
- [ ] 发布前再次执行忽略与已跟踪文件检查，确认“永不提交”项未进入版本控制。
