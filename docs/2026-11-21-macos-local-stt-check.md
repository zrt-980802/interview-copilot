# macOS 本地 Whisper 验收

日期：2026-11-21。分支：`codex/macos-support-v2`。

## 本次实现与环境

- 新增 `tools/local_stt_server.py`，以 CPU int8 加载一份本地 faster-whisper 模型，兼容应用已有的 `whisper-1` 模型别名。
- 仅监听 `127.0.0.1:8760`；提供 `/v1/models` 和 `/v1/audio/transcriptions`，支持 JSON、文本和 verbose JSON。后者保留分段时间、质量指标、音频时长与推理耗时。
- 模型下载通过 `--prepare` 显式执行，普通启动只加载已有目录，不下载权重。模型、测试音频和运行数据均留在受 Git 忽略的 `data/`。
- 本机安装 faster-whisper 1.2.1、CTranslate2 4.9.0、ONNX Runtime 1.32.0，下载多语言 base 模型。因官方端点网络受限，依赖通过清华 PyPI 镜像、权重通过 `HF_ENDPOINT=https://hf-mirror.com` 获取。
- `base` 用于功能验收，不据此宣布达到正式面试准确率要求。未下载大型 Whisper 权重或连续语音端点模型。

## 实际验证

已知合成问题为“请介绍一下智能体的规划、记忆和工具调用是如何协同工作的？”。

| 路径 | 结果 | 单次请求耗时 |
| --- | --- | --- |
| 新生成中文语音 → HTTP STT | 正确识别；忽略标点后字符错误率 0 | 约 0.77 秒 |
| 3 秒静音 → HTTP STT | 空文本，0 个分段 | 约 0.014 秒 |
| 上轮 CoreAudio/ToDesk 真实采集录音的有声片段 → HTTP STT | 正确识别题意，输出繁体字 | 约 0.43 秒 |
| 按实时速度回放 → 应用兼容音频引擎 → VAD → HTTP STT | 发出 1 条 interviewer/question，1 个语音段，0 个转写错误 | 未测全流程延迟 |

这些单次耗时不是 P50/P95，不能据此估算长期负载表现。繁体输出会影响按简体参考文本直接计算的 CER，不能将其全部记为语音内容识别错误。

上轮真实设备录音共 88.768 秒，含静音，48 kHz 双声道，归档状态 saved，无丢包或写入错误。本轮复用了该录音，新增引擎回放使用模拟 PCM 输入，不重复声称进行了真人麦克风采集。

新增 HTTP 协议测试涵盖模型别名、结构化质量字段、空音频、大小限制、非法格式及解码失败后的恢复；与 CoreAudio、STT 连接和结构化识别定向测试合计 34 项通过。真实 HTTP 非音频文件请求返回 400，依赖检查通过。本轮未重新运行整个项目测试集。

## 完整链路实测

用户提供 DeepSeek 官网凭据后，通过本地设置页启用 `https://api.deepseek.com/v1` 的 `deepseek-chat`，仅保存在当前进程内存中。接口连接检查通过，约 391 ms。凭据不写入文档、源码、模型目录或 Git。

随后重新打开真实 ToDesk Virtual Audio 输入，启用“麦克风提问测试”，播放上述合成问题，完成以下验证：

- CoreAudio 实际采集 → 校准/VAD → 本地 Whisper → 自动出题 → DeepSeek 流式快速回答 → 工作区渲染。
- 点击“完整版”后真实深挖成功；快速回答 346 字符、深挖 562 字符，均 complete、无错误。历史记录的 `quick_ms` 约 2224 ms，仅代表快速回答生成阶段，不代表说完到首字延迟。
- 历史 API 与页面均可读取问题、快速卡、深挖和来源快照；结束面试后历史显示“已结束”，录音归档 saved、0 丢包，原会话内容保留，并创建新空会话。
- 测试结束后两路采集均关闭，主服务与本地 STT 保持运行。当前回答密钥在服务重启后失效，需重新填写。

此次真实回环的 `base` 输出将“协同”识别为“鞋童”，DeepSeek 根据上下文还原并回答。该结果证明功能链路可用，也暴露了小模型的术语识别局限；模型自行还原不保证每次正确，不据此宣布正式面试质量验收完成。

设备目前只发现 ToDesk Virtual Audio，没有物理麦克风或 BlackHole。真实面试还需配置输入设备/路由，并对真人说话、背景噪声、术语与长时间运行分别验收。会话结束后的精转写设置仍选 large-v3，因未下载该权重显示“等待本地模型权重”，不影响已验证的实时 base 转写。

启动命令和模型准备方式见 [macOS 使用说明](macos.md)。
